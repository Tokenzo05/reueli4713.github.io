## 🛠️ Local Development & Hosting (XAMPP)

To verify the site's functionality in a local development environment, the application was deployed locally using **XAMPP** inside the VCASTLE environment. 

### Local Deployment Steps:
1. Installed and launched the XAMPP Control Panel.
2. Started the **Apache** web server module.
3. Moved the project files into the local Apache root directory (`htdocs`).
4. Accessed the local server via the browser using `http://localhost/`.
